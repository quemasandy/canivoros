# Embudos de venta

Registro de embudos. Cada embudo tiene un ID (`E01`, `E02`…) que no se reutiliza, aunque se descarte. Sus archivos están en la carpeta del mismo nombre.

Números: **dato** (medido) · **supuesto** (a validar) · **meta**. Lo que no se sabe: `desconocido`.

| ID | Embudo | Negocio | Tipo | Objetivo | Estado | Carpeta | Creado | Última revisión |
|---|---|---|---|---|---|---|---|---|

Estado: `borrador`, `aprobado` (por Andrés o el responsable del negocio), `en prueba`, `activo`, `pausado` o `descartado` (con el motivo en Objetivo).

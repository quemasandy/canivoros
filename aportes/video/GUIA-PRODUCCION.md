# Guía de producción para video vertical 9:16

Lineamientos técnicos y creativos para producir los guiones de este paquete.

---

## 1. Encuadre y formato

### Especificaciones técnicas

| Parámetro | Valor |
|-----------|-------|
| Relación de aspecto | 9:16 (vertical) |
| Resolución mínima | 1080 × 1920 px |
| Resolución recomendada | 1080 × 1920 px o 4K vertical (2160 × 3840 px) |
| FPS | 30 fps (estándar) o 60 fps (para cámara lenta) |
| Duración | 30–60 segundos (óptimo para Reels/TikTok) |
| Zona segura de texto | 150 px desde arriba, 250 px desde abajo (evitar íconos de UI) |

### Zonas de encuadre

```
┌─────────────────────────────┐
│  ↑ 150px zona de título     │
│  (evitar texto principal)   │
├─────────────────────────────┤
│                             │
│                             │
│      ZONA SEGURA            │
│      (contenido principal)  │
│                             │
│                             │
├─────────────────────────────┤
│  ↓ 250px zona de UI         │
│  (evitar texto importante)  │
│  (aquí van los botones)     │
└─────────────────────────────┘
```

### Tipos de plano recomendados

| Plano | Uso | Ejemplo |
|-------|-----|---------|
| Close-up | Emociones, producto, detalles | Cara del perro comiendo, textura del alimento |
| Medium shot | Interacción humano-mascota | Dueño poniendo el plato, acariciando al perro |
| Wide shot | Contexto, ambiente | Parque, sala de estar, planta de producción |
| Insert | Detalles específicos | Empaque, ingredientes, heces (episodio 4) |
| POV/Selfie | Testimoniales, UGC | Persona hablando a cámara |

## 2. Ritmo y edición

### Regla de los 2 segundos

- **Gancho obligatorio en los primeros 2 segundos.**
- Opciones de gancho:
  - Pregunta provocadora: «¿Sabías que…?»
  - Imagen impactante: plato vacío, perro triste.
  - Texto disruptivo: «POV:», «Advertencia:», «Esto te va a sorprender».
  - Sonido distintivo: silencio abrupto, sonido de notificación.

### Cortes y transiciones

| Situación | Corte recomendado |
|-----------|-------------------|
| Cambio de escena | Corte directo (sin transición) |
| Paso del tiempo | Fundido a negro breve (0.2s) |
| Antes/después | Split screen o wipe horizontal |
| Flashback | Desaturación + viñeta |
| Énfasis emocional | Cámara lenta (0.5x) |

### Ritmo general

- **Primeros 5 segundos:** Establece el problema o la curiosidad.
- **Segundos 5–20:** Desarrolla el conflicto o la información.
- **Segundos 20–35:** Giro, solución o revelación.
- **Últimos 5–10 segundos:** CTA y cierre.

### Duración de cada plano

- **Máximo 3–4 segundos por plano** en contenido dinámico.
- **Hasta 6–8 segundos** en momentos emotivos o testimoniales.
- **Evitar** planos estáticos de más de 5 segundos sin movimiento o texto.

## 3. Subtítulos y texto en pantalla

### Estilo de subtítulos

| Elemento | Especificación |
|----------|----------------|
| Fuente | Sans-serif bold (Montserrat, Poppins, o nativa de la plataforma) |
| Tamaño | Grande, legible en móvil (mínimo 48px equivalente) |
| Color | Blanco con sombra o fondo semitransparente |
| Posición | Centro-inferior de la zona segura |
| Animación | Palabra por palabra o frase completa (consistente) |

### Jerarquía de texto

1. **Título/Gancho:** Grande, centrado, primeros 2 segundos.
2. **Subtítulos de diálogo:** Debajo del centro, siempre presentes.
3. **Texto informativo:** Esquinas o lateral, más pequeño.
4. **CTA:** Grande, último frame, con flecha o ícono.

### Ejemplo de estilo

```
┌─────────────────────────────┐
│                             │
│         GANCHO              │
│    (texto grande, bold)     │
│                             │
│                             │
│                             │
│   ─────────────────────     │
│   Subtítulo del diálogo     │
│   (texto mediano, legible)  │
│                             │
│  [Logo] [CTA: Link en bio]  │
└─────────────────────────────┘
```

## 4. Look visual y paleta

### Tono visual

- **Natural y cálido:** Evitar filtros fríos o muy saturados.
- **Luz natural preferida:** Luz de ventana, exterior nublado, golden hour.
- **Sin exceso de producción:** El contenido debe verse accesible, no publicitario.

### Paleta de color sugerida (a confirmar con branding)

| Uso | Color | Hex (aproximado) |
|-----|-------|------------------|
| Primario | Verde bosque / naturaleza | `[POR CONFIRMAR]` |
| Secundario | Marrón cálido / tierra | `[POR CONFIRMAR]` |
| Acento | Naranja / energía | `[POR CONFIRMAR]` |
| Texto | Blanco o crema | `#FFFFFF` o `#FFF8E7` |
| Fondo texto | Negro semitransparente | `rgba(0,0,0,0.5)` |

**Nota:** Si existe carpeta `branding/` con lineamientos, usar esa paleta.

### Tratamiento de imagen

| Situación | Tratamiento |
|-----------|-------------|
| Escenas felices/éxito | Colores cálidos, saturación normal, luz suave |
| Escenas de problema/conflicto | Ligeramente desaturado, sombras más marcadas |
| Flashbacks o recuerdos | Viñeta suave, ligero grain |
| Producto en pantalla | Luz directa, colores precisos, sin filtro |

## 5. Lista de planos y props

### Props esenciales

| Categoría | Items |
|-----------|-------|
| **Producto** | Empaque de Canívoros (todas las presentaciones disponibles), producto suelto para mostrar textura |
| **Alimentación** | Platos de perro/gato (limpios, estéticos), bolsas de concentrado genérico (para contraste) |
| **Mascotas** | Perros de diferentes tamaños y razas, gato (para Gatívoros) |
| **Ambiente hogar** | Sala de estar, cocina, cama de mascota |
| **Ambiente exterior** | Parque, pasto, paisaje de Sopó (si es posible) |
| **Veterinaria** | Bata blanca, estetoscopio, consultorio básico |
| **Ingredientes** | Pollo crudo, salmón, vegetales (para B-roll de producción) |

### Planos recurrentes (B-roll)

Grabar estos planos una vez y reutilizar en múltiples videos:

1. **Perro comiendo con ganas** — close-up y medium shot.
2. **Textura del producto** — macro o close-up.
3. **Empaque siendo abierto** — manos, sonido de bolsa.
4. **Perro feliz corriendo/jugando** — cámara lenta.
5. **Dueño acariciando al perro** — luz cálida.
6. **Pelaje brillante** — contraluz, brillo visible.
7. **Paisaje de Sopó** — drone o wide shot.
8. **Ingredientes frescos** — tabla de cocina, luz natural.

## 6. Audio y música

### Estructura de audio

| Capa | Contenido |
|------|-----------|
| **Voz** | Diálogo, voz en off, testimonial |
| **Música** | Fondo emocional, nunca más alto que la voz |
| **SFX** | Sonido de empaque, perro comiendo, notificaciones |
| **Ambiente** | Parque, hogar, cocina (sutil) |

### Música recomendada

| Momento | Estilo de música |
|---------|------------------|
| Problema/conflicto | Tensa, mínima, piano o cuerdas |
| Curiosidad/investigación | Upbeat suave, percusión ligera |
| Solución/éxito | Emotiva, crescendo, instrumentos cálidos |
| CTA/cierre | Energética pero breve |

### Fuentes de música libre de derechos

- Biblioteca de audio de Instagram/TikTok (asegura monetización).
- Epidemic Sound (si hay suscripción).
- Artlist (si hay suscripción).
- YouTube Audio Library (gratuito, verificar licencia).

### Consideraciones de audio

- **Siempre subtitular:** 80%+ de videos se ven sin sonido.
- **Voz clara:** Grabar en ambiente silencioso, usar micrófono externo si es posible.
- **Música no reconocible:** Evitar canciones populares que distraigan o generen copyright.

## 7. Producción con bajo presupuesto

### Equipo mínimo

| Elemento | Opción económica |
|----------|------------------|
| Cámara | Celular con buena cámara (iPhone 12+, Samsung S21+, Pixel 6+) |
| Estabilización | Trípode con adaptador de celular ($20–50 USD) |
| Iluminación | Luz natural de ventana, reflector blanco (cartulina) |
| Audio | Micrófono lavalier para celular ($15–30 USD) |
| Edición | CapCut (gratis), InShot (gratis con marca de agua) |

### Tips de grabación con celular

1. **Limpiar el lente** antes de cada sesión.
2. **Bloquear exposición y enfoque** tocando la pantalla.
3. **Grabar en modo cine** si el celular lo tiene (24 fps, look cinematográfico).
4. **Evitar zoom digital** — acercarse físicamente en lugar de hacer zoom.
5. **Grabar horizontal** para algunos B-rolls y recortar a vertical en edición.

### Actores

- Equipo interno de Canívoros (autenticidad).
- Clientes reales con permiso (testimoniales).
- Familia/amigos con mascotas (bajo costo).
- **Evitar:** Actores profesionales que se vean «falsos» o publicitarios.

## 8. Producción con IA generativa

### Cuándo usar IA

| Situación | IA recomendada |
|-----------|----------------|
| Paisajes y fondos | Sí (Sopó, parques, cocinas genéricas) |
| Ingredientes y comida | Sí (pollo, salmón, vegetales) |
| Mascotas específicas | Con cuidado (puede verse artificial) |
| Personas/dueños | No recomendado (uncanny valley) |
| Producto real | No (grabar el producto real siempre que sea posible) |
| Gráficos y animaciones | Sí (explicativos, transiciones) |

### Prompts orientativos para generación de imagen

#### Paisaje de Sopó

```
Landscape photograph of Sopó, Cundinamarca, Colombia. Green mountains, 
eucalyptus trees, morning mist, golden hour light. Style: documentary 
photography, natural colors, 16:9 aspect ratio, high resolution.
```

#### Perro feliz comiendo

```
Close-up photograph of a healthy Golden Retriever eating from a ceramic 
bowl, indoor natural light from window, warm tones, shallow depth of field, 
joyful expression, 9:16 vertical format, lifestyle photography style.
```

#### Ingredientes frescos

```
Overhead photograph of raw chicken breast, fresh salmon fillet, and 
colorful vegetables (carrots, spinach) on a wooden cutting board, 
natural kitchen lighting, food photography style, appetizing, clean 
composition, 9:16 vertical format.
```

#### Textura de alimento horneado (referencia)

```
Macro photograph of baked pet food kibble with visible meat texture, 
golden brown color, crispy appearance, studio lighting, neutral 
background, product photography style, high detail.
```

### Prompts para generación de video (Runway, Pika, etc.)

#### Perro corriendo en parque

```
Video of a happy medium-sized dog running through a green park, 
golden hour lighting, slow motion, camera tracking the dog, 
joyful energy, 9:16 vertical format, 4 seconds duration.
```

#### Paisaje de Sopó con movimiento

```
Cinematic video of Colombian Andes mountains near Bogotá, morning 
mist slowly moving, eucalyptus forest, golden sunrise, drone 
flyover style, 9:16 vertical format, 5 seconds duration.
```

### Limitaciones de IA a considerar

1. **Consistencia de personajes:** Los perros generados por IA pueden verse diferentes en cada imagen. Usar un perro real como protagonista principal.
2. **Texto en imagen:** La IA tiene problemas con texto legible. Agregar texto en post-producción.
3. **Detalles de producto:** El producto de Canívoros debe ser real, no generado.
4. **Movimiento natural:** Los videos generados por IA pueden tener movimientos extraños. Usar para fondos, no para acción principal.

## 9. Checklist de pre-producción

Antes de grabar cada video:

- [ ] Guion revisado y aprobado.
- [ ] `[POR CONFIRMAR]` completados con datos reales.
- [ ] Props disponibles (producto, empaque, platos).
- [ ] Mascota disponible y alimentada (no hambrienta para la toma).
- [ ] Ubicación reservada (parque, casa, consultorio).
- [ ] Equipo cargado (celular, micrófono, luces).
- [ ] Horario de luz natural confirmado.
- [ ] Permisos de imagen firmados (si hay personas externas).

---

## 10. Checklist de post-producción

Después de grabar:

- [ ] Revisar todo el material grabado.
- [ ] Seleccionar los mejores takes.
- [ ] Editar siguiendo el guion.
- [ ] Agregar subtítulos (obligatorio).
- [ ] Agregar música y SFX.
- [ ] Verificar que el gancho funcione en los primeros 2 segundos.
- [ ] Verificar zona segura de texto.
- [ ] Exportar en 1080 × 1920 mínimo.
- [ ] Revisar en celular antes de publicar.
- [ ] Preparar caption y hashtags.

# Competencia de Canívoros en Bogotá

Registro de marcas. Cada marca tiene un ID (`C01`, `C02`…) que no se reutiliza, aunque la marca se descarte. Usa el mismo ID en `observaciones.csv`.

Evidencia: (E) visto en una fuente con URL y fecha · (D) lo dice la marca · (H) interpretación · (V) dudoso o sin fecha. Lo que no se sabe: `desconocido`.

Tipos: directo (natural cocido u horneado) · BARF y precocido · concentrado premium · alternativa casera.
